## Bewertungskriterien (Preis-Leistung)
| Kriterium | Gut | Schlecht |
|---|---|---|
| Preis (gebraucht, R30 o. vergleichbar) | < 35 000 € | > 50 000 € |
| Hersteller | MagVenture, Magstim | Hersteller ohne EU-Service |
| Baujahr | ≥ 2020 | < 2016 |
| Spule(n) inklusive | Cool-B65 / B70 (gekühlt, für Theta-Burst) | keine Spule / ungekühlte Spule |
| Theta-Burst (iTBS) möglich | ja (R30, X100, R20 mit Upgrade, Horizon, DuoMAG XT, PowerMAG) | nein |
| Zustand / Pulszähler | dokumentiert, geringe Laufleistung | unbekannt |
| CE / MDR, Service-Historie | vorhanden, Wartung durch MagVenture/Distributor | fehlt |
| Garantie / Rückgabe | ≥ 6 Monate | keine |
| Verkäufer | verifizierter Händler/Klinik | anonym, Vorkasse ins Ausland |

Warnzeichen: Preis weit unter Markt (< 15 000 € für R30) → Betrugsverdacht oder unvollständiges
Gerät; nur Grundgerät ohne Spule/Wagen; Software-Lizenz nicht übertragbar.
