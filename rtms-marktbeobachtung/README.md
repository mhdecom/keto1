# rTMS-Marktbeobachtung: MagVenture (Europa)

Wöchentliche Suche nach einem MagVenture-rTMS-Gerät (MagPro R20 / R30 / X100,
MagVenture TMS Therapy) mit gutem Preis-Leistungs-Verhältnis, europaweit (inkl. CH/UK).

## Ablauf pro Woche
1. Suche auf Marktplätzen und bei Händlern (Bimedis, eBay, MedicalExpo, Kleinanzeigen,
   Händler für Gebrauchtgeräte, MagVenture-Distributoren wie Neurolite CH, Demo-/Vorführgeräte).
2. Neue Angebote in `log.md` oben als neuen Wochenabschnitt eintragen.
3. Jedes Angebot nach den Kriterien unten bewerten (1–5 Sterne).
4. Mit den Vorwochen vergleichen: neu / weiterhin online / verschwunden / Preis geändert.

## Bewertungskriterien (Preis-Leistung)
| Kriterium | Gut | Schlecht |
|---|---|---|
| Preis (gebraucht, R30) | < 35 000 € | > 50 000 € |
| Baujahr | ≥ 2020 | < 2016 |
| Spule(n) inklusive | Cool-B65 / B70 (gekühlt, für Theta-Burst) | keine Spule / ungekühlte Spule |
| Theta-Burst (iTBS) möglich | ja (R30, X100, R20 mit Upgrade) | nein |
| Zustand / Pulszähler | dokumentiert, geringe Laufleistung | unbekannt |
| CE / MDR, Service-Historie | vorhanden, Wartung durch MagVenture/Distributor | fehlt |
| Garantie / Rückgabe | ≥ 6 Monate | keine |
| Verkäufer | verifizierter Händler/Klinik | anonym, Vorkasse ins Ausland |

Warnzeichen: Preis weit unter Markt (< 15 000 € für R30) → Betrugsverdacht oder unvollständiges
Gerät; nur Grundgerät ohne Spule/Wagen; Software-Lizenz nicht übertragbar.
